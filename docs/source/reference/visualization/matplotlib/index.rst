Matplotlib visualization
========================

The :mod:`optuna.visualization.matplotlib` module provides Matplotlib-backed
visualization functions. API documentation and executable examples now
share pages with their Plotly counterparts. Select the **Matplotlib** tab
on each page for the Matplotlib function and example.
